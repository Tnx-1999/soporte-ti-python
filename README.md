# 🛠️ Sistema de Soporte TI en Python

Proyecto desarrollado en Python enfocado en la automatización de tareas comunes en soporte técnico.

## 🚀 Funcionalidades
- Organización automática de archivos
- Gestión básica de tickets de soporte
- Lectura y análisis de logs

## 📂 Estructura del proyecto
- main.py → ejecución principal
- modules/ → lógica del sistema
- data/ → archivos de prueba

## 🎯 Objetivo
Optimizar tareas repetitivas en entornos TI, mejorando la eficiencia operativa.

## 🧠 Tecnologías
- Python
